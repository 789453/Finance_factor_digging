# 2. 总体整改目标

这次不要再以“继续修 GFN”为中心，而应以这五件事为中心：

```
1. 统一输入：DatasetSpec / UniverseSpec / TargetSpec / SplitSpec / SearchSpaceSpec / EngineSpec
2. 统一候选：FactorCandidate
3. 统一检测：SyntaxCheck / ScopeCheck / MetricCheck / NoveltyCheck
4. 统一评估：IC / IR / RankIC / RankICIR / rolling / stability / top-k / pool similarity
5. 统一输出：candidate_raw / candidate_checked / factor_pool / daily_metrics / factor_values / report

```

然后中间挖掘引擎只负责一件事：

```
MiningEngine.discover(context) -> Iterable[FactorCandidate]

```

不管这个 engine 是：

```
simple_llm
cogalpha
pysr
alphasage
alphaprobe
gfn
random_baseline
manual_formula

```

它都只产出候选表达式，不直接决定最终入池、不直接写最终报告、不直接拥有专属评估格式。

## 8.1 FactorPool

class FactorPool:
    def __init__(self, capacity: int, policy: PoolPolicy):
        self.capacity = capacity
        self.policy = policy
        self.items = []

    def add(self, report: FactorInspectionReport) -> PoolDecision:
        decision = self.policy.decide(report, self.items)
        if decision.accepted:
            self._insert_or_replace(report, decision)
        return decision
